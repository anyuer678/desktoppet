## 3. 关键约束（Windows 特性）

1. **透明窗口无法用系统边框缩放** → 尺寸只能由主进程 `setSize` 设置。
   结论：尺寸调整入口放在**控制中心**，不做边缘拖拽（v0.1 决策）。
2. `transparent:true` 时 `resizable` 需要配合自定义处理，v0.1 直接不启用系统 resize。
3. 透明区域点击会命中窗口本身 → v0.1 整窗可交互；v0.2 已升级为 `setIgnoreMouseEvents(forward)` 实现"透明区可穿透"（v0.2.0804.04，按精灵像素 alpha 判定可交互区）。

## 4. 必须落实的设计调整（已回写架构文档）

- **资源协议 `pet://`**：渲染进程无 Node 权限，读取角色图必须走 `protocol.handle('pet', …)` 映射，禁止 `file://`。
- **单入口 + hash 路由**：pet 窗口与中心窗口加载同一 index.html 的不同 hash，降低 dev 复杂度。
- **done via 控制中心**：缩放/透明度均由主进程执行。

## 5. 结论

- 整体技术路线成立，与 v0.1 范围匹配。
- 唯一需要留意的是 **Electron 依赖体积大，首装用 npmmirror**（已在 `.npmrc` 配置镜像）。
- 本项目声明 **Win10+ 支持**；多显示器、点击穿透、性能量化均已落地（v0.2）。
