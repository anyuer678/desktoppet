# DesktopPet 使用说明

版本：v1.0（正式版）

---

## 1. 运行

### 开发模式

双击 `启动.bat`，或命令行：

```bash
npm run dev
```

桌宠以透明置顶窗口出现在桌面（默认屏幕坐标 (400, 300)），带"呼吸+浮动"待机动画。

### 正式构建

```bash
npm run build        # 产物在 out/
```

## 2. 功能说明

### 2.1 桌宠本体

- 透明、无边框、置顶窗口，贴桌面显示角色主图（当前为兔兔）。
- 待机动画：呼吸 + 上下浮动，随状态变化（见 §2.4）。
- 大小与透明度可在控制中心「设置」页调整（96~512px、30%~100%），即时生效并记忆。
- **气泡消息（v0.4）**：启动时欢迎语、时段切换时问候（早上/中午/下午/晚上/深夜）；系统事件（CPU 高、内存不足、空闲、电池低等）与插件事件出现时通知说话，显示 4 秒自动消失，不挡点击。内容可在控制中心「消息」页自定义。v0.9.0807.01 起被动事件（剪贴板/目录/前台）与推送也有专属拟人化台词池，可在「消息」页为每条池输入多句台词随机选用；台词支持两个占位符：`{placeholder}`（触发内容摘要，如链接域名/文件类型，超过 24 字符截断为 `…`）与 `{title}`（推送标题）。

### 2.2 交互方式

| 操作 | 默认效果 | 说明 |
| --- | --- | --- |
| 单击兔兔 | 说一句互动台词 | 可在角色编辑器改为「打开控制中心」「弹出右键菜单」或「无动作」 |
| 双击兔兔 | 打开控制中心 | 同上 |
| 右键兔兔 | 菜单：控制中心 / 设置 / 换一个 / 隐藏 / 切换角色 / 暂停动画 / 退出 | 同上 |
| 按住拖动 | 移动兔兔，松手后位置自动记忆（下次启动原位出现） | 始终可用 |

> 交互动作可逐角色配置（v0.4）：角色编辑器「交互动作」区块选择各按键行为；「说互动台词」使用消息页的互动回应池。角色包 config.json 的 `interaction` 字段非法值自动回退默认，不影响加载。

### 2.3 点击穿透

兔兔身体（不透明像素）可点击 / 拖拽；身体周围的透明区域鼠标直接穿透到底层窗口，不影响其他程序操作。

- 判定基于角色主图逐像素 alpha（阈值 32）：半透明阴影、羽化边缘不可点。
- 面板打开时其按钮区域始终可交互。
- 排查：主进程日志 `[pet-hit] ignore = ...` 显示当前点击穿透开关状态（`true` 表示穿透开启、`false` 表示可点击）。

### 2.4 状态系统与事件中心

桌宠每 4 秒采样一次系统指标，事件经事件中心决策后广播状态：

| 状态 | 触发条件 | 兔兔表现 |
| --- | --- | --- |
| idle | 默认 | 呼吸 + 浮动 |
| focus | 工作类事件 | 呼吸变缓、浮动减小 |
| sleep | 鼠标键盘空闲 60s+ | 缓慢呼吸、不浮动 |
| happy | 成功/奖励类事件 | 快速呼吸 + 明显浮动 |
| warning | CPU>70% 或内存空闲<15% 或电池≤20% 且未充电 | 急促呼吸 |

- 状态动画缺失时自动回退到 idle（见《角色包规范》§4）。
- 事件源：CPU 占用、内存空闲率、鼠标键盘空闲时长（60s 判定入睡）、电池剩余电量（60 秒异步采样，笔记本；台式机/查询失败不产生电池事件）。

### 2.5 叠加层（夜间模式）

环境条件在基态动画上叠加修饰，不改变状态。当前支持时间条件：22:00-06:00 兔兔整体变暗、呼吸放缓、浮动减弱（`characters/rabbit/config.json` 的 `overlays`，透明背景下呈"夜色中入睡"效果）。角色可自定义叠加条件与强度。

### 2.6 控制中心

桌面宠物集中管理界面，共 10 个页签：

- **首页**：当前角色（头像 / 名称 / 版本）、陪伴统计（今日/本周陪伴时长、状态分布、互动次数，见 §2.11）、性能自检（见 §2.8）。
- **角色**：角色列表（点击切换）、导入角色包（见 §2.9）。
- **市场**：本地角色市场，未安装显示「安装」；已安装且市场版本更新显示「升级到 vX」；版本相同显示「已安装 vX」。
- **消息**：气泡消息自定义（见 §2.4 相关说明）。
- **日程**：日程提醒的新建/编辑/删除与测试。
- **统计**：陪伴统计明细（日期区间查询与图表，见 §2.11）。
- **推送**：事件推送 API 管理（服务状态/地址、Token、启用开关、调用示例与测试，见 §2.12）。
- **事件**：事件通知页（本次运行的事件流：来源/状态/高优先级筛选、单条详情、清空，见 §2.14）。
- **开发者**：被动数据源精调（剪贴板 / 目录 / 前台应用的能力与规则，见 §2.13）。
- **设置**：角色大小、透明度、开机自动启动、应用大小 / 隐藏桌宠。

### 2.7 托盘与单实例

- 系统托盘显示桌宠图标：双击显示桌宠，右键菜单（显示 / 隐藏 / 控制中心 / 退出）。
- 单实例：重复启动时不会开第二个桌宠，而是唤起控制中心窗口。

### 2.8 性能自检

控制中心首页「性能自检」按钮，5 秒采样后展示：

- 主进程 CPU 百分比（均值 / 峰值）与内存占用（RSS）。
- 渲染进程工作集内存。
- 兔兔窗口动画帧率（正常 60fps；主进程 < 10% 属正常）。

### 2.9 角色系统与导入

- 角色包位于 `characters/<id>/` 目录，规范见《角色包规范》。
- 「角色」页点击「导入角色包」→ 选择 `.pet`/`.zip` 文件，导入即完成安全校验：拒绝压缩包路径穿越（`../`）、绝对路径、缺少 `config.json`、非法 id、重复角色；失败显示具体原因，角色仓库不受污染。
- 导入成功后可点击切换；托盘右键「切换角色」菜单同步更新。
- 角色卡片带「导出」按钮：保存对话框（默认名 `<id>-v<版本>.pet`）打包分发，导出的包可再次导入；「删除」按钮（确认后删除该角色目录），删除当前激活角色时自动回退到剩余第一个角色。
- 角色卡片带「编辑」按钮：基本信息（名称/版本/默认大小/允许缩放）+ 状态动画（下拉切换状态，独立编辑呼吸与浮动参数）+ 夜间叠加层（开始/结束时间、亮度、呼吸缩放、浮动缩放、速度），保存后桌宠即时重载。

### 2.10 多显示器

- 兔兔位置按屏幕坐标记忆，可跨屏拖动。
- 拔掉显示器或分辨率变化后自动回落到主屏工作区，不会丢到屏幕外。

### 2.11 陪伴统计

统计按角色分别记录，切换角色后展示与导出随之切换。

控制中心「首页」陪伴统计卡片与「统计」页签（打开时自动刷新，之后每 15 秒自动更新，也可手动「刷新」）：

- 今日陪伴时长、本周陪伴总时长（自然周：本周一至今天）与活跃天数、连续陪伴天数（今天无记录从昨天起算）。
- 互动次数：点击 / 拖动 / 说话（仅统计有实际效果的用户交互）。
- 今日状态分布：待机 / 专注 / 睡眠 / 开心 / 告警 各占比例与时长。

「统计」页签支持自由日期区间查询（起止日期任意，限 90 天内、不可查未来；含「近7天」「近30天」快捷按钮）：

- 区间陪伴时长、活跃天数、互动总数、事件总数。
- 每日陪伴时长柱状图、状态分布堆叠图、事件趋势（含事件类型 Top5）、互动次数图；柱顶直接标注数值（时长图如「1分钟」，计数图为次数），并带虚线刻度网格，悬停柱子可查看当天明细。
- 月度热力图：按月日历格展示陪伴强度（无记录灰、其余按当月最大值分 4 档绿色），「‹ ›」自由切换月份；点击某天查看当天明细，可删除该天（二次确认）。
- 年度热力图（GitHub 风格）：全年 12 行 × 每月日历格展示陪伴强度（无记录灰、其余按全年最大值分 4 档绿色），「‹ ›」自由切换年份（2000~2100），展示全年总陪伴与活跃天数；点击任意天查看当天明细，可删除该天（二次确认）。未来的日期显示为无记录，不影响当年统计。
- 24 小时时段分布：当前查询区间内每小时累计时长柱状图（历史数据不含时段分布，自 v0.5.0805.04 起记录，旧数据会显示提示）。
- 年度汇总：本年总陪伴、活跃天数、日均陪伴（活跃日口径）、最活跃日、当前连续陪伴天数。
- 成就与里程碑：当前/最长连续陪伴天数、累计陪伴时长；等级进度条（共 10 级，达阈值升级，满级显示「已满级」）；9 枚徽章（连续陪伴 7/30/100/365 天、累计陪伴 100/500/1000 小时、活跃 30/100 天），已解锁彩色显示「✓」，未解锁半透明带锁。
- 趋势对比：近7天 / 本月 / 本年三种周期分按钮切换，与对应上期对比展示本期/上期陪伴时长、变化百分比（上期为零显示横线）、活跃天数（本期/上期）。
- 数据管理：将当前查询区间导出为 CSV（UTF-8 带 BOM，Excel 可直接打开，主进程弹出保存对话框）；生成 Markdown 周报/月报（自动对比本期与上期，含统计范围、对比表、事件 Top5，落盘到「文档/DesktopPet/报告/」，成功后显示报告路径）；按年导出 Excel（.xlsx，含每日明细与年度汇总两个工作表，主进程弹出保存对话框）；清空全部统计（二次确认，**不可恢复**，请先导出备份）。
- 自动报告（v0.7）：新增「自动报告」卡片，可为周报（启用开关 + 星期选择 + 时间）与月报（启用开关 + 日期选择 + 时间）分别配置定时，保存后持久化到 `%APPDATA%/desktop-pet/autoReports.json`。到点自动生成报告并落盘「文档/DesktopPet/报告/」，同时桌宠气泡 + Windows 系统通知提醒；若应用在预定时间未运行，启动时会静默补生成一次（仅落盘不提醒，且与手动/自动生成按周期去重）。报告文件名带周期键：`陪伴周报-<本周一>-<当天>.md`、`陪伴月报-<YYYY-MM>-<当天>.md`。

数据按角色分目录存于 `%APPDATA%/desktop-pet/stats/<角色id>/YYYY-MM-DD.json`（旧版平铺数据已自动迁移至当前角色子目录），全程本地、不联网。

### 2.12 事件推送 API（v0.8）

让第三方程序（脚本 / 软件 / 系统任务）把事件推给桌宠，桌宠以气泡 + 状态动画转达：

- 桌宠启动后在 `127.0.0.1` 的随机空闲端口开启本地 HTTP 服务，`POST /api/event` 即可推送（仅本机回环，不外网暴露）。
- 认证：请求头需带 `Authorization: Bearer <Token>`；Token 首次启动生成（32 位十六进制，存于 `%APPDATA%/desktop-pet/pushApi.json`），可在控制中心「推送」页复制、查看与重置。
- 请求体 JSON：`title`（必填，≤60 字符）、`message`（必填，≤200 字符）、可选 `type`（≤32 字符，如 `complete`/`warning`/`notice`，驱动对应状态动画，缺省 `notice`）。
- 推送成功 → 桌宠显示气泡（v0.9.0807.01 起为拟人化台词 + 标题 + 正文，8 秒）并计入当日统计（push 事件）；错误返回 JSON（401 认证失败 / 400 参数非法 / 404 路径错误 / 405 非 POST / 413 请求体超 8KB / 503 服务未启用）。推送文本池台词随机选用，「消息」页可按需自定义。
- 控制中心「推送」页签：查看服务运行状态与地址、启用/停用开关、重置 Token、复制调用示例（curl）、「发送测试」验证链路。

示例（curl）：

```bash
curl -X POST http://127.0.0.1:<端口>/api/event \
  -H "Authorization: Bearer <你的Token>" \
  -d '{"title":"构建完成","message":"测试通过，可以发布","type":"complete"}'
```

### 2.13 事件源与开发者选项（v0.9）

事件中心重构为「可插拔数据源」架构：系统监控、插件、剪贴板、目录、前台应用都是事件源，统一由源表驱动。控制中心「开发者」页签供精调三个被动数据源（默认低打扰），v0.9.0807.01 起触发时显示拟人化台词气泡（台词池与占位符见 §2.1），敏感内容不下发原文：

- **剪贴板（默认开启）**：桌宠每 3 秒轮询一次剪贴板；复制内容与上次不同且通过规则时，显示拟人化台词气泡（按链接/代码/长文/短文本/图片/敏感自动选池，台词中的 `{placeholder}` 只带链接域名或内容类型摘要，**不显示原文**）并计入当日统计。规则为逐行正则：**仅通知**（留空=全部通知）与**忽略**（任一命中即忽略），例如默认忽略纯数字与空白。敏感内容（API 密钥 `sk-`/`AKIA`/`ghp_`、私钥、13~19 位数字、6 位验证码）只提示「像密码，什么都没看见」类台词。适合给「复制即闭环」的工具（如口令、验证码、报错信息）做接入。
- **目录监听（默认关闭）**：填一个本地目录，桌上放入符合规则的新文件即气泡提示（拟人化台词 + 文件名，不显示绝对路径）并计入统计；规则为逐行通配符（`*` 任意、`?` 单字符，留空=全部）；500ms 防抖合并连续变化。适合「把文件丢进某个文件夹就触发桌宠」的自动化场景。
- **前台应用（默认关闭）**：每 15 秒检测当前最前台窗口的进程与标题（仅元数据，不读取内容），按**映射**规则决定行为：`进程名:focus` → 兔兔进入「专注」状态并显示一句台词；`进程名:ignore` → 忽略；无映射仅统计（`foreground` 事件）不打扰。适合「进入某个软件就进入专注态」的场景；依赖系统 PowerShell（缺失时静默降级）。

每项均可单独「测试」验证链路；改动后点「保存」立即生效。配置持久化于 `%APPDATA%/desktop-pet/passiveSources.json`。

### 2.14 事件通知页（v1.0）

控制中心「事件」页签展示**本次运行**的事件流（最新在前，上限 200 条，重启清空，不落盘）：

- 覆盖来源：系统监控 / 插件 / 剪贴板 / 目录 / 前台应用 / 推送 / 日程。
- 筛选：来源下拉（按当前历史实际出现的来源分组）、状态归类下拉（warning/happy/sleep/focus/idle）、「仅高优先级」（priority ≥ 8，即系统告警/插件/推送/日程，不含被动源与空闲）。
- 点击行展开详情（source/type/priority/durationMs/occurredAt 原始字段）；「清空」二次确认后清空本次记录。
- 状态徽章分色（与兔兔情绪色一致）：告警琥珀 / 开心珊瑚 / 睡眠暮紫 / 专注绿 / 待机灰绿；首页状态分布、统计图表同色系（v1.0 起）。
- 只记"新发生"的事件：同一来源+类型持续活跃时反复刷新不算新记录，避免刷屏。

## 5. 常见问题

| 现象 | 说明 |
| --- | --- |
| 控制台出现 `SSL handshake failed` | 本机代理（Clash 等）拦截 Chromium 后台请求，与桌宠功能无关，可忽略 |
| 图片不显示 | 检查角色包路径与 config.json（见 `docs/角色包规范.md`），或查看主进程日志（`%APPDATA%/desktop-pet/logs`，打包正式版为 `%APPDATA%/DesktopPet/logs`） |
| 开机启动不生效 | 仅打包后的正式版支持，开发模式下注册的是 electron.exe |
| 透明区域点不到 / 穿透不生效 | 确认主进程日志 `[pet-hit] ignore` 开关状态（`true` 表示穿透开启）；角色主图非透明背景时整窗不可穿透 |

## 6. 配置文件

> 注：用户数据目录名区分运行模式——开发模式为小写 `%APPDATA%\desktop-pet`，打包正式版为大写 `%APPDATA%\DesktopPet`（随 productName）；下文路径以开发模式书写。

用户数据在 `%APPDATA%/desktop-pet/settings.json`（位置/大小/透明度/开机启动/当前角色）。删除该文件即恢复默认。
