# DesktopPet 角色包规范

版本：1.0
状态：正式版（v0.1 起生效）
配套文档：架构设计 / API设计

本文档定义 `.pet` 角色包的标准。引擎、动画系统、插件系统、角色编辑器全部依赖此契约，**改动需走版本升级**（configVersion），禁止静默变更。

---

## 1. 角色包形态

一个角色 = 一个 `.pet`，实为 **zip 压缩包**（扩展名改为 `.pet`）。
开发期可直接用目录形式（仓库内 `characters/rabbit/`），发布/导入时打包。

```text
Rabbit.pet
├── config.json          # 必须：角色标准描述
├── avatar.png           # 必须：角色主图（透明背景）
├── preview.png          # 可选：角色列表预览图
└── animations/          # 动画资源
    └── idle/            # 每个状态一个目录，命名=状态名
        ├── 000.png
        └── 001.png
```

---

## 2. config.json 结构

版本要求：`configVersion: 1`（当前标准）。

```json
{
  "configVersion": 1,

  "id": "rabbit",
  "name": "兔兔",
  "version": "1.0",
  "author": "",
  "description": "",

  "avatar": {
    "main": "avatar.png",
    "preview": "preview.png"
  },

  "animation": {
    "default": "idle",
    "states": {
      "idle": {
        "type": "sequence",
        "path": "animations/idle",
        "loop": true,
        "fps": 8
      }
    }
  },

  "interaction": {
    "click": "speak",
    "doubleClick": "open_center",
    "rightClick": "menu"
  },

  "settings": {
    "defaultSize": 256,
    "allowResize": true
  },

  "overlays": {
    "night": {
      "condition": { "time": { "start": 22, "end": 6 } },
      "apply": { "opacity": 0.65, "template": { "breatheScale": 0.6 } }
    }
  }
}
```

## 3. 字段说明与校验

### 顶层

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| configVersion | number | ✘ | 可选，解析器不校验；当前标准为 `1`，缺失/任意值均可加载（兼容最简角色） |
| id | string | ✔ | 全局唯一，`[a-z0-9_-]`，作为配置文件名与事件 source |
| name | string | ✔ | 显示名 |
| version | string | ✘ | 角色包版本，语义化 `1.0`；缺失静默回退 `1.0` |
| author | string | ✘ | 作者 |
| description | string | ✘ | 描述 |

### 动画表（最核心）

`animation.states` 为 `<状态名, 动画定义>` 映射。状态名建议 ASCII（未强制校验，任意字符串键原样进入 supportedStates）：`idle happy sleep work warning ...`。

动画定义两种类型 `type`：

| type | 说明 | 必填字段 |
| --- | --- | --- |
| `sequence` | 序列帧动画 | `path`（指向帧目录）、可选 `fps`、`loop` |
| `template` | 模板动画：静止图 + 程序化效果 | `template` 内配置效果参数 |

**template 效果（v0.1 支持子集）：**

```json
"idle": {
  "type": "template",
  "template": {
    "breathe": { "scale": 0.02, "duration": 2400 },
    "float": { "y": 6, "duration": 3600 }
  }
}
```

| 效果 | 参数 | 说明 |
| --- | --- | --- |
| breathe | scale / duration | 呼吸缩放（竖直方向） |
| float | y / duration | 上下浮动 |
| bounce | y / duration / ease | 弹跳 |
| swing | angle / duration | 左右摇摆 |

统一规则：`loop` 默认 true；`fps` 仅 sequence 用，默认 8；`default` 必须指向 states 中已存在状态。

### 素材文件

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| avatar.main | ✔ | PNG，透明背景，正方形推荐（1024×1024 为制作基准） |
| avatar.preview | ✘ | 列表/商店展示图 |
| 序列帧 | 视动画 | 每一帧必须同尺寸、透明背景 PNG；文件名 `000.png` 起、3 位递增、连续无断号 |

### 叠加层修饰（v0.2，可选）

`overlays` 为 `<名称, 定义>` 映射，在**不改变主状态**的前提下按环境条件给动画叠加倍率因子，多个叠加层因子相乘。当前仅支持时间条件：

```json
"overlays": {
  "night": {
    "condition": { "time": { "start": 22, "end": 6 } },
    "apply": {
      "opacity": 0.65,
      "template": { "breatheScale": 0.6, "floatY": 0.4, "speed": 0.9 }
    }
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| condition.time.start / end | number | ✘ | 小时（0-23，自动取模）；`start > end` 视为跨天区间；`start === end` 永不命中；省略 condition → 始终生效 |
| apply.opacity | number (0-1) | ✘ | 精灵整体透明度倍率，与设置透明度相乘 |
| apply.template.breatheScale | number (0-2) | ✘ | 呼吸幅度倍率 |
| apply.template.floatY | number (0-2) | ✘ | 浮动距离倍率 |
| apply.template.speed | number (0.1-4) | ✘ | 动画速度倍率（同时作用于 template 时长与 sequence fps） |

校验：`condition` 存在但非法（时间非数字、apply 无任何合法字段）→ 该叠加层整体丢弃；超界数值自动夹取。

## 4. 回退规则（禁止黑屏）

引擎按状态找不到合法动画时的回退链：

```text
请求状态动画
  → 该状态存在且合法 → 播放
  → 缺失或非法 → 回退到 animation.default（idle）
  → idle 也不可用 → 显示 static avatar 主图
  → 连主图都没有 → 拒绝该角色包整体加载
```

---

## 5. 校验要点（加载器强制执行）

1. config.json 必须是合法 JSON。configVersion 可选，解析器不校验，缺失/任意值均可加载（兼容最简角色）。
2. 所有 `path` 必须是**角色包内相对路径**，禁止 `../`、绝对路径、协议外路径。
3. 序列帧由渲染层运行时按 `000.png` 起始、3 位补零探测帧数，缺素材自动回退（不在加载器强制校验）。
4. `animation.default` 必须合法存在。
5. 非法状态动画不影响其他状态，只回退该状态并记录日志。
6. 校验失败的角色包不得载入运行，不得崩溃；错误写入主进程日志，UI 显示加载失败提示。

---

## 6. 预留扩展（不破坏现有结构）

`config.json` 顶层预留以下**并列 key**，v1 不建议加入核心包，扩展独立包：

```json
{
  "sound":     { "...": "" },
  "emotion":   { "...": "" },
  "physics":   { "...": "" },
  "live2d":    { "model": "..." },
  "plugins":   { "...": "" },
  "gestures":  { "...": "" }
}
```

约定：**新增一律追加新 key，不修改已定义 key 的语义。** 互相依赖不得引入循环引用（color 挂在 emotion 内不挂顶层）。

## 8. 导入与校验（v0.3）

控制中心「角色」页可导入 `.pet`/`.zip` 角色包（v0.3 已实现）。导入流程与约束：

1. 解压到临时目录，仅接受**相对路径**条目；拒绝 `../`、绝对路径、盘符、空路径段，以及 Windows 保留设备名（`con`/`prn`/`aux`/`nul`/`com1-9`/`lpt1-9`）与 NTFS ADS（条目名含 `:`）。
2. 防 zip bomb：条目数 ≤ 5000、单条目 ≤ 200MB、解压总字节 ≤ 1GB，超限直接拒绝。
3. 必须存在根目录 `config.json`（子目录下的同名文件不算）。
4. `config.json` 必须能解析出合法 `id`（`[a-z0-9_-]+`）与 `name`，动画定义按本规范校验。
5. 目标 id 已存在 → 默认拒绝导入；`overwrite=true` 覆盖升级：先备份旧目录，成功导入后删除备份，失败自动恢复旧版（不污染角色仓库）。
6. 校验通过后整个目录移入 `characters/<id>/`，原包不落盘、角色仓库不被部分写入污染。

导出（v0.3）：控制中心「角色」页「导出」按钮把角色目录打包为 `.pet`（默认名 `<id>-v<版本>.pet`），config.json 位于根目录，与导入格式一致，可分发、可再导入。

打包：zip 根目录放 `config.json` + 素材，扩展名 `.pet` 或 `.zip` 均可。

## 9. 变更流程

- 对 `configVersion` 的字段行为有改动的，必须 bump `configVersion` 并提供迁移。
- 兼容新增（如追加只读字段）允许 bump 次版本（`1.0 → 1.1`）。
- 本文档变更同步更新：实现加载器 / 校验器 / 编辑器，三者必须一致。
